프로그램이 자동으로 진행하는 선물 자동매매 프로그램입니다.

풀오토 트레이딩은 비트코인 선물거래와 코인선물거래를 위한 코인 자동매매 프로그램입니다. 비트코인·이더리움·리플·솔라나 USDT 무기한 선물을 설정한 조건에 따라 자동으로 매매하며 익절과 손절도 프로그램이 관리합니다. 선물거래는 원금 손실 위험이 있으며 수익을 보장하지 않습니다.

주요 기능

01

조건 확인 후 진입

여러 조건으로 추세를 확인하고, 조건이 맞을 때만 진입해 불필요한 매매를 줄입니다.

02

단계별 익절

수익이 늘어나는 구간마다 익절선을 끌어올려, 올라간 수익을 지키는 방식으로 청산합니다.

03

손절 후 재진입

추세가 유지되면 조건을 다시 확인해 재진입하고, 재진입 거래에는 별도의 손절 기준이 적용됩니다.

04

연속 손실 정지

연속 손실이 일정 횟수에 이르면 신규 진입을 멈춰 계좌를 보호합니다.

05

시간봉 선택

1분·5분·15분·1시간 중 선택할 수 있으며, 시간봉에 맞춰 익절·손절 기준이 자동으로 정해집니다.

06

내 PC에서 실행

프로그램은 내 컴퓨터에서 실행되고 API 키도 내 PC에만 저장됩니다.

07

쉬지 않는 24시간 365일 가동

프로그램이 켜져 있는 동안 365일 24시간 시장을 지켜보며, 조건이 맞으면 진입부터 청산까지 진행합니다. (PC가 켜져 있어야 합니다)

08

설정은 한 번, 원칙대로 감정 없이

UID·API 키·레버리지·증거금 비중만 입력하고 시작 버튼을 누르면 됩니다. 공포와 욕심에 흔들리지 않고 미리 정한 원칙대로 실행합니다.

09

현물과 다른 하락장 대응

현물은 오를 때만 수익을 기대할 수 있지만, 선물은 양방향으로 매매가 가능해 하락장에서도 수익 기회를 노릴 수 있습니다.(방향이 틀리면 손실도 커질 수 있습니다)

10

만든 사람의 커리어 확인

프로그램을 만든 운영자의 수상 경력과 자격을
관리자 소개 및 문의에서 직접 확인할 수 있습니다.

선물거래는 원금 손실 위험이 있으며, 풀오토는 매매를 보조하는 도구로 수익을 보장하지 않습니다.

승인 받는 방법

아래 DEEPCOIN 로고를 누르면 안내된 링크로 바로 가입할 수 있습니다.

DEEPCOIN
셀퍼럴 페이백 20% 지급✔ 트래블룰 연동 한국 거래소: 빗썸 · 코인원 — 국내 거래소에서 바로 입금·출금이 가능합니다.
안내 더 이상 게이트아이오 거래소 연동은 API KEY 지원 문제로 지원하지 않습니다.

승인 절차

  1. 위 DEEPCOIN 로고를 눌러 안내된 링크로 가입합니다.
  2. 가입 후 본인의 UID를 확인합니다.
  3. UID를 전달하기 전에 선물 지갑으로 500 USDT 이상의 자금을 이동해 주세요.풀오토는 최소 증거금 500 USDT 이상을 유지해야 사용할 수 있습니다.
  4. 관리자에게 UID를 전달합니다.문의 방법은 「관리자 소개 및 문의」 메뉴에서 확인하세요.
  5. 승인이 완료되면 프로그램을 내려받아 사용할 수 있습니다.

API키 발급 방법

프로그램이 내 계정으로 주문을 내려면 API 키가 필요합니다. 아래 순서대로 따라 해주세요.

DEEPCOIN
1

UID 확인 → API Management

  • 우측 상단 프로필 메뉴를 엽니다.
  • UID를 확인해 메모합니다. (승인 신청에 필요)
  • API Management를 클릭합니다.
2

Create API 설정

  • Remark: 알아보기 쉬운 이름 입력
  • Password: API 전용 비밀번호 입력
    8~20자 · 대/소문자·숫자·특수문자 포함 · 분실하지 않게 메모
  • Authorization: Trade만 체크 (출금 권한 금지)
  • Bind IP: Do not bind IP 선택
  • Confirm을 클릭합니다.
3

보안 인증

  • Email: Get Code → 이메일 인증번호 입력
  • Google: 구글 OTP 6자리 입력
  • Confirm을 클릭합니다.
이 이후에는 API KEY와 SECRET KEY가 나옵니다. 절대 노출하지 마시고, 따로 컴퓨터에 메모만 남겨놔 주세요.
API 키는 타인에게 알려 주지 마세요. 관리자도 API KEY·SECRET KEY를 절대 요구하지 않습니다.

자주 묻는 질문

질문을 누르면 답변이 펼쳐집니다.

UID는 어디서 확인하나요?
각 거래소 마이 페이지에 들어가시면 9자리 숫자로 UID를 확인할 수 있습니다.
프로그램이 안 켜져요
지정된 거래소 가입 경로로 가입하여 승인을 받지 못하면 프로그램 사용이 제한됩니다. 자세한 사항은 「승인 받는 방법」을 참고해 주세요.
사용 방법을 모르겠어요
아래 사진의 설정대로 입력해 주세요. 거래소 UID, API Key, Secret Key를 입력하고 기준 봉 주기, 레버리지, 증거금 비중, 감시 종목을 선택한 뒤 시작하면 됩니다. 증거금 비중은 100%로 설정할 수 없습니다.
풀오토를 사용하려는데 얼마가 필요한가요?
풀오토를 사용하기 위해서는 최소 증거금인 500 USDT 이상을 유지하여야 합니다.
게이트아이오 거래소는 이용이 불가한가요?
기존 사용자들은 지속 사용이 가능하지만, 신규 사용자는 API KEY 인식 불가로 사용을 제한합니다.
수익이 보장되나요?
아니요. 풀오토는 매매를 보조하는 도구이며 수익을 보장하지 않습니다. 선물 거래는 원금 손실과 청산 위험이 있으니 감당할 수 있는 범위에서 사용해 주세요.
API 키는 어떤 권한으로 만들어야 하나요?
선물(Futures) 거래 권한만 켜고, 출금 권한은 반드시 끄세요. 자세한 방법은 「API키 발급 방법」에서 확인할 수 있습니다.
프로그램을 끄거나 PC가 꺼지면 어떻게 되나요?
프로그램이 꺼지면 익절·손절 감시도 함께 멈춥니다. 이미 잡혀 있는 포지션은 거래소에 그대로 남아 있으니, 포지션이 있는 상태에서는 프로그램과 PC를 켜 두시고, 종료할 때는 거래소 앱에서 포지션 상태를 꼭 확인해 주세요.
어떤 종목을 매매하나요?
비트코인(BTC), 이더리움(ETH), 리플(XRP), 솔라나(SOL) 중에서 원하는 종목을 선택해 감시할 수 있습니다.
매매 내역은 어디서 확인하나요?
프로그램 하단의 「매매기록 보기」 버튼에서 확인할 수 있습니다. 익절·손절 기준은 「수익/손실 기준 보기」 버튼에서 볼 수 있습니다.
백신 프로그램이 경고를 띄워요
새로 만든 프로그램은 일부 백신이 경고를 띄울 수 있습니다. 반드시 이 홈페이지의 「풀오토 다운로드」 메뉴에서만 내려받으시고, 다른 곳에서 받은 파일은 사용하지 마세요. 문의는 관리자에게 해 주세요.
업데이트는 어떻게 확인하나요?
프로그램의 「공지사항」 버튼과 오픈채팅방, 이 홈페이지의 다운로드 메뉴에서 최신 버전과 업데이트 내역을 확인할 수 있습니다.

업데이트 내역

v1.14 최신 버전

  • DEEPCOIN 거래소 지원 추가 (거래소 선택 + API 비밀번호 입력)
  • DEEPCOIN은 소액으로 먼저 테스트한 뒤 사용을 권장

새 버전으로 덮어쓰는 방법

  1. 실행 중인 풀오토를 완전히 종료합니다.포지션이 열려 있다면 거래소 앱에서 상태를 먼저 확인하세요.
  2. 위 「최신 버전 다운로드」 버튼으로 새 파일을 받습니다.
  3. 기존 풀오토 파일이 있는 폴더에 새 파일을 붙여 넣고, 같은 이름이면 「바꾸기(덮어쓰기)」를 선택합니다.
  4. 풀오토를 실행하고 창 제목의 버전 번호가 최신인지 확인합니다.입력해 둔 설정은 같은 폴더에 저장되므로 폴더를 지우지 않으면 그대로 유지됩니다.

※필독 유의사항

프로그램을 사용하기 전에 반드시 읽어 주세요.

  1. 본 프로그램은 매매를 보조하는 도구이며, 수익을 보장하지 않습니다.
  2. 선물 거래는 원금 손실 및 청산 위험이 있으며, 모든 투자 판단과 결과의 책임은 사용자 본인에게 있습니다.
  3. 과거 성과나 테스트 결과는 미래의 결과를 보장하지 않습니다.
  4. API 키는 본인만 관리해야 하며, 출금 권한은 부여하지 마세요.
  5. 풀오토는 증거금이 500 USDT 미만이면 최소 증거금 부족으로 거래가 멈출 수 있습니다. 최소 500 USDT 이상을 유지해 주세요.
    증거금 부족으로 인한 손실은 사용자 본인의 사유이며, 운영자는 이에 대해 책임을 지지 않습니다.
  6. 더 이상 게이트아이오 거래소 연동은 API KEY 지원 문제로 지원하지 않습니다.
  7. 프로그램의 불법 복제 및 무단 도용은 형사처벌을 받을 수 있습니다.
  8. 관리자를 사칭하는 사람이 있습니다. 풀오토 관리자와 매니저는 절대 개인정보를 묻거나 요구하지 않으며, 사칭하는 사람이 나타나면 바로 관리자에게 알려 주세요.
고배율 고비중은 청산의 지름길입니다. 무리한 매매는 삼가 주세요.
