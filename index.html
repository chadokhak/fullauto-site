fullauto.kr

매매는 [ 풀오토 ]가,
설정은 단 한 번만.

정해 둔 원칙에 따라 진입부터 수익까지
프로그램이 자동으로 진행하는 선물 자동매매 프로그램입니다.

풀오토 트레이딩은 비트코인 선물거래와 코인선물거래를 위한 코인 자동매매 프로그램입니다.
비트코인·이더리움·리플·솔라나 USDT 무기한 선물을 설정한 조건에 따라 자동으로 매매하며,
익절과 손절도 프로그램이 관리합니다.
선물거래는 원금 손실 위험이 있으며 수익을 보장하지 않습니다.

주요 기능

01

조건 확인 후 진입

여러 조건으로 추세를 확인하고,
조건이 맞을 때만 진입해
불필요한 매매를 줄입니다.

02

단계별 익절

수익이 늘어나는 구간마다 익절선을 끌어올려,
올라간 수익을 지키는 방식으로 청산합니다.

03

손절 후 재진입

추세가 유지되면 조건을 다시 확인해 재진입하고,
재진입 거래에는 별도의 손절 기준이 적용됩니다.

04

연속 손실 정지

연속 손실이 일정 횟수에 이르면
신규 진입을 멈춰 계좌를 보호합니다.

05

시간봉 선택

1분·5분·15분·1시간 중 선택할 수 있으며,
시간봉에 맞춰 익절·손절 기준이 자동으로 정해집니다.

06

내 PC에서 실행

프로그램은 내 컴퓨터에서 실행되고,
API 키도 내 PC에만 저장됩니다.

07

쉬지 않는 24시간 365일 가동

프로그램이 켜져 있는 동안 365일 24시간 시장을 지켜보며,
조건이 맞으면 진입부터 청산까지 진행합니다.
(PC가 켜져 있어야 합니다)

08

설정은 한 번, 원칙대로 감정 없이

UID·API 키·레버리지·증거금 비중만 입력하고
시작 버튼을 누르면 됩니다.
공포와 욕심에 흔들리지 않고
미리 정한 원칙대로 실행합니다.

09

현물과 다른 하락장 대응

현물은 오를 때만 수익을 기대할 수 있지만,
선물은 양방향으로 매매가 가능해
하락장에서도 수익 기회를 노릴 수 있습니다.(방향이 틀리면 손실도 커질 수 있습니다)

10

언제 어디서든 원격 시작·정지

밖에서도 폰의 텔레그램 봇으로
매매를 시작하고 정지할 수 있고,
진입 알림도 바로 받아볼 수 있습니다.원격 봇 연결 방법 보기

선물거래는 원금 손실 위험이 있으며,

원격 봇 연결 방법

폰의 텔레그램으로 매매를 정지·시작하고, 진입 알림을 받는 선택 기능입니다.
봇은 내가 직접 만들며 1분 정도 걸립니다.

⚠️ 반드시 확인하세요
풀오토 · 컴퓨터 · 텔레그램이
항상 켜져 있어야 합니다.
✅ 풀오토 가동 시 윈도우 자동 절전 모드는 꺼집니다.
컴퓨터가 꺼지거나 인터넷이 끊기거나 풀오토를 종료하면
원격 명령도, 진입·청산 알림도 전달되지 않습니다.
매매 중에는 풀오토가 자동 절전을 막아 주지만,
직접 절전·최대 절전·종료를 누르거나 노트북 덮개를 닫으면 멈춥니다.
  1. 텔레그램에서 BotFather를 검색해서 열고
    시작을 누릅니다.이름이 정확히 BotFather이고
    파란 인증 표시가 있는 계정만 사용하세요.
  2. 대화창의 /newbot 을 누릅니다.
  3. 봇 이름을 물으면 풀오토 원격 이라고 입력하고,
    이어서 봇 아이디를 입력합니다.봇 아이디는 영어와 숫자만 쓸 수 있고, 끝이 반드시 bot 이어야 합니다.
    가운데에 본인 거래소 UID를 넣으면 겹치지 않습니다.
    예: fullauto_remote_본인UID_bot
    「username is invalid」가 나오면 한글·공백이 섞였거나 끝이 bot이 아닌 경우입니다.
    「already taken」이 나오면 이미 쓰는 아이디이니 숫자를 바꿔 다시 입력하세요.
  4. 완료 메시지에 나오는 긴 토큰(숫자:영문 글자)을
    복사합니다.토큰은 비밀번호와 같습니다.
    다른 사람에게 보내거나 화면을 공유하지 마세요.
    풀오토 관리자도 토큰을 절대 묻지 않습니다.
  5. 방금 만든 봇 이름이 맞는지 확인하고 시작을 누릅니다.
  6. 풀오토에서 「텔레그램 원격 사용」 스위치를 켜면 입력 창이 뜹니다.
    토큰을 붙여 넣고 확인을 누르세요.토큰이 확인되면 6자리 연결 코드가 표시됩니다.
    창을 닫아도 연결은 유지되며, 스위치를 끄기 전까지 계속 사용됩니다.
  7. 봇 대화창에 화면에 표시된 6자리 숫자를 보내면
    연결이 완료됩니다.「연결되었습니다」라는 답이 오면 끝입니다.
    다른 폰으로 바꿀 때는 스위치를 껐다 켜서 새 코드를 받으세요.
  8. 봇 호출 방법: 봇 대화창에 !봇 이라고 입력하면
    봇이 활성화되어 메뉴가 나옵니다.번호를 누르면 한 번 더 확인하고, 예를 눌러야 실행됩니다.

메뉴 설명

  1. 정지 — 신규 진입만 멈춥니다.
    열려 있는 포지션의 익절·손절 감시는 계속합니다.
  2. 전체청산 — 열려 있는 포지션을 모두 시장가로 청산하고,
    신규 진입을 중단합니다.
  3. 시작 — 신규 진입을 다시 시작합니다.
    프로그램이 정지 상태라면 매매를 시작합니다.
  4. 상태 — 잔고와 보유 포지션을 바로 알려 줍니다.
포지션에 진입하거나 청산되면 자동으로 알림이 옵니다.
알림에는 종목, 현재가, 진입가가 표시되며,
자세한 내용은 거래소에서 확인해 주세요.
풀오토가 켜져 있는 PC가 인터넷에 연결되어 있어야 합니다.
PC가 꺼져 있으면 명령이 전달되지 않으니,
포지션이 열려 있을 때는 거래소 앱에서도 상태를 확인하세요.
봇 하나는 프로그램 하나에만 연결해 주세요.

  • 청산 사유를 익절(보호선) / 청산(추세이탈)로 나누어 표시
  • 같은 API 키로 풀오토를 중복 실행하지 못하게 방지
  • 매매기록에 진입 시간·청산 시간 표시 (불타기 시 처음 진입가와 평균가 함께 표시)
  • 진입 직후 포지션을 못 읽어도 30초 안에 자동으로 이어받아 감시
  • 로그·매매기록 파일 자동 저장 (fullauto_log.txt / fullauto_trades.csv)
  • 텔레그램 원격을 켜고 끄는 스위치로 변경 (꺼두면 토큰 입력칸이 숨겨짐)
  • 실시간 진행 로그 창을 더 크게 확대
  • API 키 입력칸을 켜고 끄는 스위치로 변경 (꺼두면 매매 설정이 간단하게 보임)
  • 화면 세로 길이를 줄여 작은 모니터에서도 한눈에 보이도록 개선
  • 화면 배치 개편 (왼쪽 매매 설정, 오른쪽 공지·사용방법·텔레그램·매매 시작 버튼)
  • 공지사항·사용 방법·수익/손실 기준·매매기록을 새 창으로 열도록 변경
  • 텔레그램 원격 스위치를 매매 설정 안으로 이동, 실시간 포지션/로그 칸 크기 1:1로 조정
  • API 키·텔레그램 봇 토큰을 새 입력 창에서 입력하도록 변경 (확인 후 창을 닫아도 유지, 스위치를 끄면 삭제)
  • 프로그램을 처음 켰을 때 화면 크기를 조정해 로그칸까지 모두 보이도록 개선
  • 매매 중에는 윈도우가 자동으로 절전 모드에 들어가지 않도록 개선

새 버전으로 덮어쓰는 방법

  1. 실행 중인 풀오토를 완전히 종료합니다.포지션이 열려 있다면 거래소 앱에서 상태를 먼저 확인하세요.
  2. 위 「최신 버전 다운로드」 버튼으로 새 파일을 받습니다.
  3. 기존 풀오토 파일이 있는 폴더에 새 파일을 붙여 넣고,
    같은 이름이면 「바꾸기(덮어쓰기)」를 선택합니다.
  4. 풀오토를 실행하고 창 제목의 버전 번호가 최신인지 확인합니다.입력해 둔 설정은 같은 폴더에 저장되므로
    폴더를 지우지 않으면 그대로 유지됩니다.

※필독 유의사항

프로그램을 사용하기 전에 반드시 읽어 주세요.

  1. 본 프로그램은 매매를 보조하는 도구이며, 수익을 보장하지 않습니다.

    모든 투자 판단과 결과의 책임은 사용자 본인에게 있습니다.
  3. 과거 성과나 테스트 결과는 미래의 결과를 보장하지 않습니다.
  4. API 키는 본인만 관리해야 하며, 출금 권한은 부여하지 마세요.
  5. 풀오토는 증거금이 500 USDT 미만이면
    최소 증거금 부족으로 거래가 멈출 수 있습니다.
    최소 500 USDT 이상을 유지해 주세요.

    운영자는 이에 대해 책임을 지지 않습니다.
  6. 더 이상 게이트아이오 거래소 연동은
    API KEY 지원 문제로 지원하지 않습니다.
  7. 프로그램의 불법 복제 및 무단 도용은 형사처벌을 받을 수 있습니다.
